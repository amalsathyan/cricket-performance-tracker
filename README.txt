CRICKET PERFORMANCE TRACKER – INSTALLABLE WEB APP

Files:
- index.html: app interface and tracker logic
- manifest.webmanifest: install metadata
- sw.js: offline caching
- icon.svg: app icon

INSTALL ON IPHONE:
1. Upload the contents of this folder to a static web host that provides HTTPS.
2. Open the published HTTPS address in Safari on the iPhone.
3. Tap Share > Add to Home Screen.
4. Enable Open as Web App (if shown), then tap Add.
5. Launch it from the Home Screen. Open it once while online so the offline cache can be installed.

DATA:
Records are stored in browser localStorage on that device/browser. They do not sync to another device. Use Progress > Export CSV and Backup data regularly. Restore backup imports a JSON backup. Clearing website data or uninstalling/resetting the browser may remove records.

SCHEDULE ASSUMPTION:
Two gym sessions + two cricket practices + one weekend match = three cricket sessions total. Adjust days around match day and avoid hard lower-body training in the 48 hours before a match when practical.

SAFETY:
This is a training log, not a medical device. Neck-specific strengthening and loaded spinal correction require physiotherapist guidance given the supplied DAVID findings. Adjust or stop exercises that provoke symptoms and consult a clinician.
